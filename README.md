# STOP! あおり運転

東名高速を **東京IC から名古屋IC** まで走る3Dドライブゲーム。あおってきた車だけをミサイルで撃退しながら進む。

公開URL: https://game.chozo.net/stop-aori/

## 遊び方

- あおり運転をしてきた車（パッシング・クラクション・割り込み・急ブレーキ）をミサイルで撃退する
- 次のどれかでミス。**累計3回でゲームオーバー**（ミスは回復しない）
  - あおる前の車を撃つ
  - 一般車・トラック・バス・急いでいるだけの車に当てる
  - 他の車にぶつかる（接触のあと2秒間は無敵）
- **覆面パトカー**に当てるとミス2
- ミサイルは前と後ろにまっすぐ100m飛ぶ。あおり車の蛇行やかわす動きで外れると、そのまま飛んで、100m以内にいる一般車に流れ弾として当たる（ミス）
- 名古屋ICに着けばクリア（100km/hで約3分）

### 操作

| | PC | スマホ（縦向き・横向きどちらでも） |
|---|---|---|
| 車線変更 | ← → （A D） | 左下の ◀ ▶ |
| 加速・減速 | ↑ ↓ （W S） | ◀ ▶ の上の「加速」「減速」 |
| 前へ発射 | Z / Space | 右下の「前へ発射」 |
| 後ろへ発射 | X | 右下の「後ろへ発射」 |
| 一時停止 | Esc / P | 右上の Ⅱ |
| 音のオン・オフ | M | 右上の 🔊 |
| 全画面 | — | タイトルの「全画面で遊ぶ」、右上の ⛶（Android の Chrome など。iPhone の Safari は非対応のため出ない） |

### スマホ向けの作り

- 画面全体を使う。縦向きは後方モニターを上に大きく出し、カメラを高くして3車線と後ろの車が入るようにしている。横向きは後方モニターを上の中央に出す
- 文字とボタンは画面の短い辺に合わせた大きさで、最小サイズを決めている。端末の切り欠き・ホームバーを避ける
- 重い端末では、後方モニターを1コマおきに描き、それでも重ければ描画の解像度を段階的に下げる（軽くなれば戻す）
- 画素密度が2倍以上の端末ではアンチエイリアスを切る
- ミス・接触・撃退で端末を振動させる（対応端末のみ）

## 仕様

- 視点は自車の斜め後ろ上。画面上部に後方モニター（ミラーと同じ左右反転）
- 車がすぐ後ろまで車間を詰めてくると「後方から接近」を表示（あおり車かどうかは教えない）
- あおり行動をした車には「あおり」の札が付く。これが撃ってよい合図
- あおり車は開始2秒で出てきて、いつも2〜4台が絡んでくる（序盤2台→終盤4台）。1台が走り去ると1.5〜3秒で次が来る。後ろ（50m）からだけでなく、前方（70〜100m）からも出てくる
- 1台のあおり車が、次の手口を最大5つまで繰り出す（同じ手口は続けない。45秒で走り去る）
  - **車間詰め**: 後ろから蛇行しながら迫り、車間を詰めてパッシングとクラクション
  - **割り込み＋急ブレーキ**: 横の車線から追い越し、前に割り込んで急ブレーキ
  - **前で蛇行・進路妨害**: 前で蛇行し、こちらが車線を変えると前に回り込む
  - **ムダブレーキ**: 前でブレーキを小刻みに踏む（ブレーキランプが点滅）
  - **並走・幅寄せ**: 横に並んでクラクションを鳴らしながら寄ってきて、そのまま抜いて割り込む
- 前方から出てきたあおり車は、自車の前に入って待ち構える。ムダブレーキや蛇行を始めるまでは、撃つとミス
- あおり車は真横から車線に入ってこない（横からぶつけない）。車線を変えられても、まず車間を保つ
- 蛇行の幅は序盤1.8m→終盤2.3m（2つの波を重ねて読みにくくしている）。自車の真後ろ・真ん前から約1.25m以上ずれた瞬間に撃つと外れる。タイミングを見ずに撃つと、序盤は約3割、終盤は約5割外れる（かわす動きを除く）
- 後方モニターの中央の赤い点線が、後ろへ撃ったミサイルの通り道。あおり車がこの線に重なった瞬間が撃ちどき。外れると「外れた！」と出る
- 命中の演出: 閃光・オレンジの火の玉・火花・飛び散る破片（車体の色）・地面を走る衝撃波・周りを照らす光・黒煙。撃たれた車は宙に跳ねて転がり、表か裏返しで路肩に止まって、しばらく燃える。爆発の粒は撃たれた車と一緒に流れる。撃退すると爆発の場所から「撃退！ +1000」が立ち上る。命中の瞬間は画面が白く光り、時間が一瞬ゆっくりになる（ヒットストップ）。爆発音は破裂音・爆風・低音・パチパチ音を重ねている
- 紛らわしい車
  - 急いでいるだけの車: 速く走って車線変更が多いが、車間は空けている
  - 覆面パトカー（進み具合20%から）: しばらく後ろに付いてくるが、あおらない
- 進むほど、絡んでくるあおり車の数、蛇行の幅、ミサイルをかわす確率（15%→50%）が上がる。ただし、かわすのは自車から離れているときだけ。車間10m未満では必ず当たり、10〜20mで少しずつかわしやすくなり、20m以上で上の確率どおりにかわす（`aori.dodgeNear` / `dodgeFar`）。3分の走行で、あおり行動は約80回（2秒に1回ほど）起きる
- 距離表示は実際の km（東京IC〜名古屋IC 約326km）。東名高速の終点は小牧ICだが、ゴールは名古屋ICにしている。ゲーム内のコースは 5.4km に縮めている
- IC を通過したときは、チャイムの音だけで知らせる（画面には出さない。道路の上の案内標識には IC 名が出る）
- ゲームオーバー・クリアの瞬間からは、終わりの音以外（周りの車のクラクションやエンジン音など）を鳴らさない
- IC の km は東京ICからのおおよその値（ゲーム用の目安）
- スコア: 撃退 ×1000、クリア +5000、残りミス数 ×1500、200秒より早く着いた1秒ごとに +25

調整値はすべて `src/config.ts` にある。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 判定・ゲームの中身・バランスのテスト（vitest）
npm run build      # 型チェック + dist/stop-aori/ に出力
npm run e2e        # ビルド済みのものをヘッドレスChromeで確認（PC 1280×720、スマホ縦 390×844・横 844×390・小 360×640）。画面は tools/out/ に保存
npm run ogp        # OGP画像 public/ogp.png を作り直す（npm run dev を別に起動しておく）
npm run deploy     # ビルドして Cloudflare Workers に公開
```

## 公開

Cloudflare Workers（静的アセット）で `https://game.chozo.net/stop-aori/` に公開している。`wrangler.jsonc` で `game.chozo.net/stop-aori` と `game.chozo.net/stop-aori/*` のルートだけを受け持つ（workers.dev は使わない）。ビルドは `dist/stop-aori/` に出力され、`public/` の `favicon.svg` と `ogp.png` もそこにコピーされる。

OGP画像は `tools/ogp/make-ogp.mjs` で、前に割り込んだあおり車を前方ミサイルで撃った直後の場面を撮り、タイトルと遊び方を重ねて作る。爆発の粒は毎回少し違う形になる。

### ファイル構成

```text
src/
  config.ts   調整値
  route.ts    東名のICと km
  rules.ts    命中の判定・スコア
  sim.ts      ゲームの中身（描画なし。車の動き・あおりの行動・ミサイル・接触）
  render.ts   Three.js の描画・演出・後方モニター
  models.ts   車・吹き出し・標識をコードで作る
  scenery.ts  道路と景色（街・丘・富士山・海・茶畑・IC標識）
  audio.ts    効果音（Web Audio で合成）
  main.ts     画面の切り替え・操作・HUD・確認用の入口 window.__game
tests/        単体テストと自動プレイ（bot.ts）
tools/e2e.mjs ブラウザでの確認
tools/ogp/    OGP画像を作るスクリプト
public/       favicon.svg と ogp.png（1200×630）
```

画像・音のファイルは使っていない（すべてコードで作っている）。

### バランス確認（12通りの乱数で自動プレイ）

| 操作 | クリア | 撃退（平均） |
|---|---|---|
| 何もしない | 0 / 12 | 0 |
| ミサイルを撃ちまくる | 0 / 12 | 0 |
| 避けるだけ（撃たない） | 0 / 12 | 0 |
| 避けて、あおった車が真後ろ・真ん前に重なった瞬間だけ撃つ | 2 / 12 | 約15 |

自動プレイは反応が0.45秒遅れ、前の車を見て車線を変えるだけの単純な運転なので、人間がうまく立ち回ればもっとクリアできる見込み。難しすぎる場合は `src/config.ts` の `aori.activeStart` / `activeEnd`（絡んでくる数）、`brakeDecel`（急ブレーキの強さ）で調整する。

`npm test` の `tests/acts.test.ts` が、あおり行動の回数と自動プレイの結果を表示する。
